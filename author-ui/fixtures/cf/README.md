`wknd-shared.json` holds the responses of `/bin/studio/cf.json` (models, model, folder, fragment) for the WKND shared
content fragments, written by `studio-cfm`'s `ContentFragmentTest` with `-Dstudio.cf.dump=<dir>`. The content is from
`aem-guides-wknd-shared.ui.content` (MIT License, (c) Adobe). Used by the content fragment tests.
